# Product-Sales-Analysis

A data analysis project focused on product sales performance using Excel, SQL, and Power BI.

🛠 Tools & Technologies

* Microsoft Excel
* SQL
* Power BI

📊 Excel Dashboard

Interactive dashboard analyzing total price, shipping cost, orders, quantity, delivery days, products, regions and payment methods.

📈 Power BI Dashboard

Interactive Power BI dashboard analyzing sales by product, region, payment method and customer type.

🗄️ SQL Analysis

SQL queries covering filtering, aggregation, grouping, sorting, CASE WHEN, HAVING, DISTINCT and window functions.

🔍 Key Insights

* Total sales: 4.38M
* Total quantity: 16K
* Total orders: 1,500
* Average delivery time: 6 days
